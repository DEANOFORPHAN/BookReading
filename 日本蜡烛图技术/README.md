# 日本蜡烛图技术

> 书目：史蒂夫·尼森《日本蜡烛图技术》  
> 节奏：每天约 20 分钟，分为两个高密度讲解单元，每个单元后进行一次简短问答  
> 预计周期：30 天  
> 目标：理解价格形态背后的多空心理，形成可复习、可验证的观察框架。

## 学习原则

- 蜡烛图表达的是特定背景下的概率与情绪，不是独立的买卖指令。
- 观察形态时，同时检查趋势、支撑阻力、成交量和后续确认。
- 先描述图上事实，再提出解释；区分“看到什么”和“认为会发生什么”。
- 所有内容仅用于技术分析学习，不构成个性化投资建议。

## 每日课程规范

- 每课约 20 分钟，安排两个 8-9 分钟的高密度讲解单元，并保留 2-4 分钟总结。
- 每个讲解单元后只进行一次简短问答，通常为 1-2 题；集中订正后立即进入下一单元，避免把一个知识点拆成过多轮互动。
- 每课至少配一张直观的 K 线结构图或情境对比图，不能只用文字描述形态。
- 插图统一保存在 `插图/`，并嵌入对应的每日笔记或概念卡片。
- 图中应标明趋势背景、关键价格以及确认与失效条件；图形用于辅助理解，不作为确定性预测。
- 技术名词首次出现时必须先用日常语言解释，不假设读者已有股票或技术分析基础。
- 用户的作答、疑问和订正应追加到当日笔记，形成连续学习记录。

## 预计学习路线

课程参考原书“基础形态 -> 组合形态 -> 与其他技术工具结合”的结构，但按概念掌握程度推进，不按页码平均分配。

| 阶段 | 天数 | 主要内容 |
| --- | ---: | --- |
| 基础语言 | 第 1-3 天 | K 线结构、趋势、支撑阻力、成交量与确认 |
| 反转形态 | 第 4-10 天 | 锤子线、上吊线、吞没、刺透、乌云盖顶、孕线等 |
| 星线与十字线 | 第 11-16 天 | 启明星、黄昏星、十字星及其市场心理 |
| 持续形态 | 第 17-20 天 | 窗口、三法等趋势延续结构 |
| 综合工具 | 第 21-26 天 | 趋势线、回撤、均线、指标和成交量的配合 |
| 案例与复习 | 第 27-30 天 | 综合识图、失效案例、错题复盘和个人检查清单 |

当前进度：**第 3/30 天学习中，约 10%**。若某个基础概念尚不清楚，在当天两个讲解单元内补足，不额外拉长整体周期。
