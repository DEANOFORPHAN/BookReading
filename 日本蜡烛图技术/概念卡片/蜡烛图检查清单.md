# 蜡烛图检查清单

![[../插图/蜡烛图五步检查清单.svg]]

## 五步顺序

1. **趋势**：先判断上涨、下跌还是横盘。
2. **位置**：看当前价格是否接近支撑区、阻力区或区间中部。
3. **K 线**：描述实体、影线、收盘位置和四个价格。
4. **成交量**：判断参与程度是否高于近期正常水平。
5. **条件**：写出确认条件和失效条件。

## 标准记录格式

```text
背景：
位置：
观察：
假设：
确认：
失效：
风险：
```

## 核心原则

- 先描述图上事实，再提出解释。
- 支撑和阻力是区域，不是绝对价格点。
- 成交量是辅助证据，不是单独的方向信号。
- 没有失效条件的形态判断不完整。
- 形态用于观察概率，不用于替代仓位和风险控制。
